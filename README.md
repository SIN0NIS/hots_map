# 히오스 전장 기록 재생기 + 전술 보드

Heroes of the Storm **리플레이(.StormReplay)를 브라우저에서 바로 열어**
고화질 전장 지도 위에 재생하고, 그 위에 펜·핀·영웅 토큰으로 전술을 그리는 도구다.
설치도 서버도 필요 없다 — `index.html` 을 브라우저로 열면 끝.

제작자 SINONIS · Claude AI 도움받아 제작

## 할 수 있는 것

화면 맨 위에서 **「🗺 맵 보기」 / 「▶ 리플레이 분석」** 두 모드를 오간다.

- **맵 보기** — 지도와 전술 도구만 나온다 (재생바·이벤트 로그는 감춰진다).
  끌어서 이동, 휠로 확대, 드롭다운으로 전장 전환. 리플레이 없이 작전판으로 써도 된다.
- **리플레이 분석** — `.StormReplay` 파일을 열면 브라우저 안에서 파싱해
  (Pyodide + heroprotocol 계열), 10명의 영웅 이동을 지도 위에 재생한다.
  배경은 그 리플레이의 전장으로 고정된다 (「✕ 리플레이 닫기」로 해제).
- **전장 지도 19종** — 정식 전장 15개 + 무작위 난투 4개
  (브락시스 전초기지 · 공업 지구 · 잃어버린 동굴 · 은빛 도시). 좌표 정렬은 자동.
- **화질 두 단계** — 평소에는 가벼운 판(맵당 약 0.5MB)을 써서 빨리 열리고,
  왼쪽 아래 **「🔍 고화질」** 을 누르면 원본(맵당 약 10MB, 내장 그림 13920×7848)을
  받아 갈아 끼운다. 보던 확대 위치는 그대로 유지된다.
  지도는 캔버스에 굽지 않고 SVG 그대로 얹으므로 확대해도 그 화질이 그대로 나온다.
- **팬·줌** — 휠/더블탭/두 손가락. 모바일 터치 지원.
  전장이 다 보이는 배율보다 더 줄지 않고, 그 16배까지만 확대된다.
  지도 바깥의 빈 곳으로는 밀려나지 않는다.

### 리플레이 화면

화면 배치는 `reference/heroes-of-the-storm-analyzer` (직접 만든 UI 시안) 를 옮겨 왔다.
짙은 넥서스 블루 바탕에 아케인 골드 강조, 팀은 하늘색 / 진홍으로 나눈다.

```
┌ 머리줄  로고 · 맵 보기 / 리플레이 분석 · 파일 조작 ──────────────┐
├ 스코어보드  1팀 5명 │ 시계·레벨·킬·건물 │ 2팀 5명 ──────────────┤
├ 지도 (+ 전술 도구)                     │ 이벤트 로그           │
│                                        ├───────────────────────┤
│                                        │ 지표 그래프           │
├ 이벤트 타임라인  재생 조작 + 1팀/2팀 시간축 ─────────────────────┤
└──────────────────────────────────────────────────────────────────┘
```

- **스코어보드** — 게임 관전 UI 배치를 따랐다:

  ```
  [초상화] [1 · 4 · 7 · 10 특성]  이름    레벨          [수치]
    ↖궁극기 [13 · 16 · 20 특성]  닉네임
  ```

  실제 관전 바처럼 초상화·특성·레벨을 빈 자리 없이 붙였다. 특성은 위 줄이 1·4·7·10,
  아래 줄이 13·16·20 이고, 10레벨 궁극기는 초상화 왼쪽 아래에 동그랗게 겹쳐 붙는다.
  2팀은 좌우를 뒤집어 가운데를 마주 본다.
  특성은 찍은 시점이 되면 불이 들어오고, 방금 찍은 것은 3초간 금색 테두리가 뜬다.
  스킬을 쓰면 초상화 테두리가 번쩍이고, 초상화를 누르면 그 줄이 강조된다.
- **📊 통계 / 🎓 특성 창** — 스코어보드 오른쪽 위 단추 (또는 `S` / `T` 키) 로 따로 연다.
  통계는 게임 종료 화면과 같은 표다:
  **킬 · 어시 · 죽음 · 공성 피해 · 영웅 피해 · 치유 · 보호막 · 경험치**.
  열 머리를 누르면 그 항목으로 정렬되고, 항목마다 1등이 금색으로 뜬다.
  «＋ 자세히» 를 누르면 받은 피해·막아낸 피해·미니언 처치·재생구슬·용병 점령·
  적 제어 시간 등 15개가 더 나온다.
  두 창 모두 **팀별로 묶어** 보여 준다. 특성 창은 선수 10명의 7티어 픽을 한 표로 내고,
  지금 시각까지 찍은 것만 밝게, 아직 안 찍은 칸은 ✕ 로 표시한다.
  가운데 기둥에는 시계와 양 팀의 **레벨 · 킬 · 건물** 이 좌우로 놓이고, **앞서는 쪽만 팀 색**으로 켜진다.
  아래 **특성 / 관여 / 파밍 / APM / XP** 단추로 오른쪽 수치 칸의 내용을 갈아 끼운다
  (파밍 = 그때까지 막타로 잡은 미니언·용병과 주운 재생구슬).
- **스코어보드 접기** — 위 막대의 `⌄` 또는 **`Tab`** 으로 **펼침 → 한 줄 → 숨김** 세 단계.
  «한 줄»은 시계·레벨·킬·건물만 가로로 남기고, «숨김»은 통째로 치운다.
  1512×860 화면 기준으로 지도 높이가 **381px → 601px → 644px** 로 늘어난다.
  숨긴 뒤에는 머리줄의 «⌃ 스코어보드» 로 되돌린다.
- **하단 이벤트 타임라인** — 위 줄이 1팀, 아래 줄이 2팀이다.
  💀킬 · 🗼포탑 · 🏰요새 · 🏯성채 · 👑핵 · ⚔️용병 · 🪶목표가 시간축에 찍힌다.
  **표식 크기는 사건의 무게**를 따른다 (핵 > 성채 > 요새 > 포탑, 킬은 관여자 수만큼 커진다).
  아직 오지 않은 사건은 옅고, 지나온 구간은 옅은 금색으로 채워진다.
  표식이나 줄 아무 데나 누르면 그 시각으로 건너뛴다. 재생 조작 막대의 `⏮` `⏭` 는 사건 단위로 넘긴다.
- **우측 레일** — 위쪽이 이벤트 로그(머리줄에 «지나온 것 / 전체» 개수), 아래쪽이 지표 그래프.
  그래프는 항목(돌격병·용병·영웅 처치·구조물·시간 경과)을 골라 볼 수 있고,
  **`⤢` 또는 `G` 키**로 큰 창을 연다. 큰 창에는 2분 눈금 · 레벨 문턱선 ·
  항목별 색 나누기 · **«경험치 얼마 = 몇 레벨» 표**가 붙는다.
- **구간 통계** — 두 시점을 찍으면 그 사이에 무슨 일이 있었는지 표로 낸다.
  하단 조작 막대의 `⟦` `⟧` 또는 **`[` `]`** 키로 양끝을 찍고 `Σ 구간`(또는 `\`)으로 연다.
  찍은 구간은 타임라인에 금색 띠로 남는다.
  팀 비교(처치·사망·건물·용병·목표·경험치 항목별·레벨 변화)와
  선수별 표(관여·데스·미니언·용병·건물·구슬·APM·사망 시간)가 같이 나온다.
  «오브젝트 구간에 누가 얼마나 벌었나» 같은 것을 바로 볼 수 있다.
  (참고: [SpazzoReplayStatKit](https://github.com/spazzo966/SpazzoReplayStatKit) 의 타임스탬프 기록)
- **사망 표시** — 죽은 영웅은 죽은 자리에 회색으로 남아 있다가 부활 시각에 되살아난다.

### 전술 보드

- 🖌 도구를 켜면 지도 위에 펜(검정 테두리)으로 그리고, 핀을 꽂고,
  영웅 아이콘 핀/토큰을 배치할 수 있다. 영웅 검색(한/영), 팀 색(청/적),
  크기 조절, 끌어서 이동, 🗑로 삭제, `Ctrl+Z` 되돌리기.
  놓인 것을 누르면 금색으로 강조되고, 맨땅을 누르면 강조가 풀린다.
- **영웅 고르기** — 90명이라 한 줄로 늘어놓으면 찾기 어렵다. 위의 역할군 칩으로 추린다:
  🛡전사 13 · ⚔투사 17 · ✚치유사 16 · ✦지원가 4 · 🗡근접 암살자 10 · 🏹원거리 암살자 30.
  (역할은 게임 데이터의 `expandedRole` 을 그대로 쓴다 — `tools/build_roles.py`)
  검색창에 한글·영문을 치면 역할군과 상관없이 전체에서 찾는다.
- **놓은 뒤에도 바꾼다** — 말이나 핀을 고르면 그 자리에서 팔레트가 열린다.
  색·팀·초상화·크기를 눌러 바로 갈아 끼울 수 있고, ● 를 누르면 초상화를 떼고
  기본 색 핀/번호 말로 돌아간다. 바꾼 것은 `Ctrl+Z` 로 하나씩 되돌아간다.
  (파괴된 구조물 표식도 색을 바꿀 수 있다)
- **우클릭 빠른 메뉴** — 지도 아무 데나 우클릭하면 도구 메뉴가 그 자리에 뜬다.
  좌클릭이나 `1`~`6` 으로 고른다 (6 = 모두 지우기, 이것도 `Ctrl+Z` 로 되돌아간다).
  도구 패널을 열지 않아도 한 글자 단축키로 바꿀 수 있고, 고른 도구는 커서 모양으로도 보인다.
- **📋 배치보드로 복사** — 리플레이의 **지금 이 순간**을 그대로 보드에 옮긴다.
  살아 있는 영웅은 제자리에, 죽은 영웅은 죽은 자리에 회색으로,
  그때까지 파괴된 구조물은 ✕(포탑·요새·성채)/★(핵) 표식으로 찍힌다.
  한 번의 `Ctrl+Z` 로 통째로 취소된다.
- **영웅 표시 크기** — 화면 아래 「영웅 크기」 손잡이.
  리플레이에서는 지도를 확대해도 초상화 크기가 화면상 그대로 유지되고,
  맵 보기에서는 보드에 놓인 영웅 말 크기를 바꾼다.
- **글씨 크기** — 화면 아래 「글씨」 손잡이로 90~150% 까지. 다음에 열 때도 기억한다.

## 바로 쓰기

두 가지 방법:

1. **웹에서 바로** — <https://sin0nis.github.io/hots_map/> 를 연다.
   예제 리플레이 8개를 «예제 ▾» 메뉴에서 바로 불러볼 수 있다.
2. **내려받아 열기** — [저장소를 받아](https://github.com/SIN0NIS/hots_map)
   `index.html` 을 크롬·엣지로 연다. `file://` 로 열어도 동작한다.
   리플레이 파싱은 최초 1회 Python 엔진을 내려받으므로 그때만 인터넷이 필요하다.

리플레이 파일은 보통 여기에 있다:
`문서\Heroes of the Storm\Accounts\<번호>\<지역-Hero-번호>\Replays\Multiplayer`

## 리플레이에서 무엇을 어디까지 알 수 있나

이 도구가 «기록 그대로 보여 주는» 부분과 «추측하는» 부분을 구분해 둔다.

### 기록 그대로인 것

사망·부활 시각, 특성 선택, 레벨업, 팀 경험치 내역(30초 간격),
건물 파괴 시각과 위치, 용병 점령, 오브젝트 획득, 스킬 사용 시각.

### 15초마다만 아는 것 — 영웅 위치

게임이 남기는 위치 스냅샷은 **15초 간격**뿐이다. 그 사이는 아래 순서로 메꾼다.

1. **스냅샷이 최우선** — 15초마다 오는 실제 좌표로 맞춘다.
2. **이동 명령** — 그 사이에 유저가 우클릭한 지점을 향해 최대 이동속도로 간다.
3. **스킬 조준점** — 스킬을 쓴 좌표도 «그때 그 근처에 있었다» 는 단서로 쓴다.
4. **지형 충돌** — 벽·낭떠러지를 통과하지 못한다 (`js/data_pathing.js` 의 통행 격자).
5. **길찾기** — 목적지가 지형 건너편이면 A\* 로 우회로를 따라간다.

즉 전투 중 세밀한 무빙까지 재현하지는 못하고, 「어디로 이동했는지」 수준의 동선을 본다.

**얼마나 맞는지 재어 두었다** — 리플레이 안의 참값(사망 좌표·위치 스냅샷)을 하나씩
가리고 맞히게 하는 홀드아웃 검증이다 (`tools/evaluate.py`). 표본 8판 기준:

| 무엇을 뺐나 | 평균 오차 | p95 |
|---|---|---|
| 아무것도 안 뺌 (지금) | **5.1 타일** | 13.3 |
| 길찾기를 뺌 | 11.1 | 65.4 |
| 이동 명령을 뺌 | 15.5 | 69.8 |
| 다 빼고 앵커만 (직전 위치 유지) | 19.1 | 83.2 |

256타일 맵에서 중앙값 3.7타일(1.4%)이다. **A\* 길찾기가 단연 최대 기여**이고,
그다음이 이동 명령이다. 화면의 「신뢰도」를 켜면 어디가 확실하고 어디가 짐작인지
아이콘 흐림과 점선 원으로 보여 준다.

### 리플레이에 아예 없는 것 (그래서 재현하지 않거나 추측하는 것)

- **군중 제어(CC)** — 기절·둔화·속박이 언제 걸렸는지는 리플레이에 **어떤 형태로도 남지 않는다**
  (표본 26판 전수 확인). 그래서 「스턴 걸려서 멈춤」은 재현하지 않는다.
- **건물을 누가 부쉈나** — 39건 중 4건에만 남는다. 나머지는 **위치로 주인 팀을 알아내고
  그 반대 팀이 부쉈다고 판정**한다. (검증: 구조물이 팀당 정확히 반씩 갈리고,
  잃은 건물의 «시각 ↔ 자기 핵까지 거리» 상관이 −0.86 — 공성이 안쪽으로 밀고 들어오는 모양 그대로다.)
- **킬과 어시의 구분** — 리플레이는 관여자 목록만 남기고 막타를 구분하지 않는다.
  그래서 킬/어시 대신 히오스 기준인 **처치 관여(Takedown)** 로 센다.
- **스킬이 Q/W/E/R 중 무엇인지** — 리플레이에는 내부 번호(abilLink)만 남는다.
  쿨타임을 지문 삼아 맞춰 봤지만 **60%** 밖에 안 맞았다 (10개 중 4개가 엉뚱한 스킬이 된다).
  그래서 «지금 이 스킬이 쿨인가» 는 보여 주지 않고, 스킬 칸에는 그 영웅이 가진
  스킬과 **기본** 재사용 대기시간만 적는다. 방금 쓴 것은 슬롯 단위 막대로만 표시한다.
- **퀘스트 스택** — «몇 개 모았나» 를 세는 값이 리플레이에 없다. 특성 관련 기록은
  `SUpgradeEvent` 인데 리플레이 25판을 훑어 보니 설정용 표식(팀·성문 열림 등)과
  «퀘스트 완료» 표식 두 종뿐이고, 진행 중인 개수를 세는 항목은 없다.
- **실시간 쿨다운** — «지금 이 스킬이 몇 초 남았나» 는 알 수 없다. 스킬 사용 기록에
  내부 번호만 남아 Q/W/E 중 무엇인지 못 가리기 때문이다 (위 참고).
  대신 영웅 피해량·치유량 같은 **최종 수치는 다 있다** — 경기 종료 점수표
  (`SScoreResultEvent`) 에 항목 134개 중 74개가 채워져 들어 있고, 📊 통계 창이 그것을
  그대로 보여 준다. 다만 «경기 전체» 값이라 재생 위치를 되감아도 바뀌지 않는다.
  시각에 따라 변하는 값은 스코어보드의 통계 페이지와 **구간 통계**가 맡는다.
- **레벨 경험치 문턱값** — 30초 간격 표본만 남아 정확한 값을 알 수 없다.
  표본 리플레이 8판을 겹쳐 **하한**을 뽑아 `Lv7 13,891+` 처럼 «이 값 이상» 으로 적는다
  (`js/data_levels.js`). 상한(레벨업 직후 표본)은 30초어치를 통째로 넘겨 짚어 쓸 수 없다.

## 자주 묻는 것

**Q. 지도와 마커가 어긋난다** — 맵 보기의 «배경 월드범위» X/Y 숫자를 조절하면 된다.
내장 지도는 자동 정렬되지만, 직접 올린 배경은 수동 조절이 필요할 수 있다.

**Q. 리플레이 버전** — 파서는 프로토콜 91756(2.55.x) 기준이다. 최신 패치
리플레이는 대부분 그대로 읽히지만, 아주 오래된 리플레이는 실패할 수 있다.

**Q. 지도는 어떻게 만들었나** — 게임 설치 파일에서 전장 데이터를 추출해
직접 만든 3D 렌더러로 구운 탑다운 정사영이다. 별도 저장소의
`viewer3d.html` 파이프라인 참고.
